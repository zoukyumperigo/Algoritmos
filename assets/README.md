# Assets Folder

## Logo Setup

To display the company logo in the application header:

1. Save your logo image as `logo.png` in this folder (`assets/logo.png`)
2. The logo should be in PNG format with transparent background for best results
3. Recommended size: 200x200 pixels or similar square aspect ratio
4. The logo will be automatically displayed at 60px height in the header

## Current Logo

The app is configured to display the **Século Verde Frozen Foods** logo.

If the logo file is not found, the header will still display correctly with just the text branding.
