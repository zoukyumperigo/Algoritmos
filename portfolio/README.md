## 🎨 DESIGN SYSTEM

### Colors
- **Deep Space:** `#0A0E14` (background)
- **Cyan Accent:** `#00F5FF` (primary interactions)
- **Mint Green:** `#00D9A3` (success/metrics)
- **Text Primary:** `#E6EDF3`
- **Text Secondary:** `#8B949E`

### Typography
- **Font:** Inter (body), JetBrains Mono (code/metrics)
- **Headings:** 64px / 48px / 36px / 24px
- **Letter spacing:** -0.02em (tight, futuristic)

### Animations
- Smooth scroll
- Fade + slide on scroll
- Hover effects (glow, scale)
- Count-up animations for metrics

## 📝 CUSTOMIZATION

### 1. Update Content
Edit case studies in `app/systems/[project]/page.tsx`

### 2. Change Colors
Modify `tailwind.config.js`:
```js
colors: {
  cyan: '#YOUR_COLOR',
  // ...
}
```

### 3. Add/Remove Sections
Components are modular — import/export as needed

### 4. Contact Form
Currently static. Integrate with:
- Formspree
- EmailJS
- Custom API endpoint
